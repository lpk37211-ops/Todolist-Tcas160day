# แผนพิชิต TGAT + TPAT3 90+ (160 วัน)

React + Vite + Tailwind app พร้อม deploy บน Vercel ข้อมูล (เช็คลิสต์รายวัน / คะแนนรายสัปดาห์ / Error Log)
ถูกเก็บไว้ใน localStorage ของเบราว์เซอร์ผู้ใช้แต่ละคน (ไม่มี backend/ไม่มีการเก็บข้อมูลส่วนกลาง)

## รันทดสอบในเครื่องตัวเองก่อน (ไม่บังคับ แต่แนะนำ)

ต้องมี Node.js ติดตั้งไว้ก่อน (ดาวน์โหลดที่ nodejs.org ถ้ายังไม่มี)

```bash
npm install
npm run dev
```

จะเปิดที่ http://localhost:5173

## วิธี Deploy ขึ้น Vercel

### วิธีที่ 1: ผ่าน GitHub (แนะนำ ใช้งานง่ายสุด อัปเดตทีหลังได้ง่าย)

1. สร้าง repo ใหม่บน GitHub แล้วอัปโหลดโฟลเดอร์นี้ทั้งหมดขึ้นไป (ลาก-วางไฟล์ในหน้าเว็บ GitHub ก็ได้ ไม่ต้องใช้ command line)
2. เข้า https://vercel.com แล้ว Sign up / Log in (ใช้บัญชี GitHub ล็อกอินได้เลย)
3. กด "Add New..." → "Project"
4. เลือก repo ที่เพิ่งอัปโหลด แล้วกด "Import"
5. Vercel จะจับ Framework เป็น "Vite" ให้อัตโนมัติ ไม่ต้องตั้งค่าอะไรเพิ่ม กด "Deploy"
6. รอประมาณ 1 นาที จะได้ลิงก์ เช่น `your-project.vercel.app` ใช้งานได้ทันที

### วิธีที่ 2: ผ่าน Vercel CLI (ไม่ต้องใช้ GitHub)

```bash
npm install -g vercel
cd โฟลเดอร์นี้
vercel
```

ตอบคำถามตามที่ CLI ถาม (login / ตั้งชื่อ project) แล้วมันจะ deploy ให้อัตโนมัติ
ครั้งต่อไปที่แก้ไขโค้ดแล้วอยากอัปเดตเว็บ ให้รัน `vercel --prod` อีกครั้ง

## ข้อควรรู้

- ข้อมูลที่กรอก (เช็คลิสต์/คะแนน/Error Log) เก็บอยู่ใน localStorage ของ **เบราว์เซอร์+อุปกรณ์นั้น ๆ เท่านั้น** ถ้าเปลี่ยนเครื่องหรือเปลี่ยนเบราว์เซอร์ ข้อมูลจะไม่ตามไปด้วย และถ้าล้าง browser data ข้อมูลจะหาย
- ถ้าอยากใช้กับหลายอุปกรณ์พร้อมกันโดยข้อมูลซิงก์กัน จะต้องเพิ่มระบบฐานข้อมูล/บัญชีผู้ใช้เข้ามา (เช่น Supabase, Firebase) ซึ่งไม่ได้รวมอยู่ในเวอร์ชันนี้
- แผนเริ่ม 23 ส.ค. 2569 จบ 29 ม.ค. 2570 (ก่อนสอบ 30 ม.ค. – 1 ก.พ. 2570) ระบบคำนวณ "วันนี้" จากนาฬิกาเครื่องผู้ใช้อัตโนมัติทุกครั้งที่เปิด
